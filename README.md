# projeto-travels
Projeto de site de viagens
Este projeto foi construído com conhecimentos adquiridos nas ferramentas HTML e CSS. O design e do projeto foi feito com inspiração em outros designs através de pesquisa no Pinterest. O foco não é o design em si, mas o domínio das tecnologias HTML e CSS.

O maior desafio, ainda, é a responsividade da página, mas neste projeto, ao meu ver, a resposividade foi devidamente aplicada.
